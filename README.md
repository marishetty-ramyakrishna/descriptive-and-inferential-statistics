## 📊 Descriptive Statistics

Descriptive statistics focuses on organizing, summarizing, and presenting the characteristics of a dataset.

Common descriptive measures include:

* Mean
* Median
* Mode
* Range
* Variance
* Standard Deviation

### Measures of Central Tendency

Central tendency describes the center or typical value of a dataset.

**Mean**

The mean is calculated by adding all observations and dividing by the number of observations.

**Median**

The median is the middle value when the observations are arranged in order.

**Mode**

The mode is the value that occurs most frequently.

### Measures of Variability

Variability describes how spread out the observations are.

Important measures include:

* Range
* Variance
* Standard Deviation

## 🔬 Inferential Statistics

Inferential statistics uses sample data to make conclusions or predictions about a larger population.

Instead of studying an entire population, researchers can analyze a sample and use statistical methods to make inferences about the population.

### Population and Sample

```text
Population
    ↓
Sample
    ↓
Statistical Analysis
    ↓
Inference about Population
```

## 📈 Descriptive vs Inferential Statistics

| Descriptive Statistics                | Inferential Statistics                            |
| ------------------------------------- | ------------------------------------------------- |
| Summarizes collected data             | Draws conclusions from sample data                |
| Describes a dataset                   | Makes inferences about a population               |
| Uses measures such as mean and median | Uses statistical inference techniques             |
| Focuses on what the data shows        | Helps make conclusions beyond the observed sample |
